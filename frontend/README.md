# Comvoly

Comvoly is an AI-powered Community Intelligence Platform.

The goal is to help communities preserve, search and understand their collective knowledge by connecting platforms such as Telegram, Discord, Slack and others into a single intelligent knowledge base.

## Vision

Every community contains valuable knowledge.

Comvoly ensures that knowledge is never lost and can be discovered instantly through AI-powered search and intelligent retrieval.
